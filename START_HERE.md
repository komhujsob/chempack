# Первый запуск: 2 минуты

## На твоём Mac

1. Скачай исходники: на странице GitHub нажми **Code → Download ZIP**.
2. Распакуй ZIP и открой получившуюся папку.
3. Дважды нажми **Запустить.command**. Нужен Python 3.11 или новее. Библиотеки устанавливать не требуется.
4. В открывшемся окне нажми **Попробовать демо**.

Если запуск двойным щелчком не сработал, открой Terminal, введи `cd `, перетащи в него распакованную папку и нажми Enter. Затем выполни:

```bash
python3 -m chempack
```

## Собрать свои материалы

1. Нажми **Выбрать папку** и выбери отдельную папку с результатами проекта.
2. Посмотри столбцы **Образец** и **Тип**. Это предположения по названиям файлов. Дважды нажми на строку, чтобы исправить назначение или исключить файл. Можно выделить несколько строк сразу.
3. В поле **Ожидаемые типы** оставь `1H,13C` или укажи свой список, например `1H,13C,19F,HRMS`. Программа покажет, какие типы не помечены у каждого найденного образца.
4. Нажми **Собрать пакет** и выбери папку назначения вне исходной.
5. Открой каталог и проверь содержимое. Для передачи коллегам возьми **ChemPack.zip**. После распаковки они смогут открыть **index.html** и перейти по ссылкам к файлам.

Удачные имена: `BDP-01_1H.pdf`, `BDP-01_13C.pdf`, `BDP-01_HRMS.csv`. Свою схему переименовывать необязательно: назначения можно исправить в окне.

Оригиналы остаются на месте. Точные копии отмечаются, но все выбранные файлы попадают в пакет. Экспериментальные данные из чатов и Drive в этот репозиторий не включены.

## На Windows

В распакованной папке открой **Запустить.bat**. Нужен установленный Python 3.11+. Остальные действия те же.

Подробности и команды для терминала — в [README.md](README.md).
